## [0.1.0] - 2026-10-28

### Added

- Desktop-style workspace with menu bar, tab bar and status bar
- JSON formatting, minifying and validation with line/column errors
- Collapsible JSON tree view with path and value copying
- Structural JSON diff
- JSONPath queries and filter expressions
- JSON flatten / unflatten
- Key sorting, recursive sorting and dropping empty values
- JSON Schema and TypeScript interface generation
- Mock data generation from a template
- Conversion between JSON and CSV / XML / YAML / TOML / INI
- Excel import and export
- JSON escaping and GET query string conversion
- Base64 / Unicode / URL encoding and decoding
- English, Simplified Chinese, Traditional Chinese, Japanese and Korean UI
- Light / dark / system theme
- Offline single-file build (`dist-single/index.html`)
